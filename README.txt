MY MUSE — Frontend prototype

วิธีเปิด:
1. แตกไฟล์ my-muse.zip
2. เปิดโฟลเดอร์ด้วย VS Code
3. เปิด index.html ด้วย Live Server
   - ถ้ายังไม่มี Live Server ให้ติดตั้ง Extension ชื่อ "Live Server"
4. หน้าเว็บหลักอยู่ที่ index.html

หน้าเว็บ:
- index.html = Home
- explore.html = Explore
- guide.html = Beauty Guide
- mylooks.html = My Looks
- profile.html = Profile
- style.css = ดีไซน์ทั้งหมด
- script.js = interaction เล็ก ๆ

หมายเหตุ:
- ตอนนี้เป็น Frontend prototype ก่อน ยังไม่มี Database / Login / Upload รูปจริง
- รูปตัวอย่างใช้ URL จาก Unsplash สามารถเปลี่ยนเป็นรูปของโปรเจกต์ได้
- ถ้าจะทำระบบจริง ค่อยต่อ Backend/API และ Database ภายหลัง
